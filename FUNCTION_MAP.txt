Control confirmation
  Every web key press sends the documented KEY,<code>,P command, then performs a fresh STS read and returns/renders the scanner display as confirmation.

Audio
  No background port-554 probe.
  Listen Live owns RTSP startup: TCP connect -> OPTIONS -> DESCRIBE -> SETUP -> PLAY.
  GET_PARAMETER keeps the same session alive.
  Final audio owner release sends TEARDOWN before close.
  Browser WAV source is exposed only after real RTP is received.
